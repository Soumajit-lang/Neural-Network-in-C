# Neural Network From Scratch in C

A basic feedforward neural network implemented completely in C without using external machine learning libraries.

## Features
- Forward propagation
- Sigmoid activation function
- Random weight initialization
- Multi-layer neural network structure
- Pure C implementation

## Technologies Used
- C Programming
- GCC Compiler
- VS Code
- MinGW-w64

## Learning Outcome
This project helped me understand:
- Fundamentals of neural networks
- Activation functions
- Weight initialization
- Low-level AI implementation

## Compile

```bash
gcc neural_network.c -o nn -lm
